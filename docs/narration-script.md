# Kingdom Dating — Narration Script (ElevenLabs)

Paste each line into ElevenLabs, download it as **mp3**, and save it with the
**exact file name** shown. All files go in `public/narration/`.
If a file is missing, the app simply stays silent at that moment.

**Voice:** deep, warm, slightly mysterious storyteller. Slow pace. Leave a short
pause at each "…". Keep each clip under ~15 seconds.

## Moments

| File name | Plays when | Line |
| --- | --- | --- |
| `welcome.mp3` | The Gate opens | Who approaches the gate? … In this realm, no one sees your face. They only hear your voice. Choose who you are, and step through. |
| `trials-intro.mp3` | Before the first trial | Three trials stand between you and the realm. Courage. Heart. Mischief. … Answer with your voice. Laugh, hesitate, be wild. Be you. |
| `riddle.mp3` | Tonight's Riddle opens | The moon has risen … and with it, a new riddle. Answer before dawn. |
| `match.mp3` | Two people match | Two voices … one heartbeat. Your masks have fallen. Go, speak to each other. |
| `level-up.mp3` | Someone reaches a new level | The realm has noticed you. … You have risen. |

## Trial questions

Each clip = the short scene line, a pause, then the question.
